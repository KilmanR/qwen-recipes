## Как добавлять рецепт

1. Открывается файл нужного раздела в `recipes/` (или создаётся новый).
2. Рецепт оформляется по шаблону: название, порции, ингредиенты, приготовление, примечания, БЖУ (если считалось).
3. Строка раздела переносится из комментария в таблицу выше, статус меняется с ⏳ на ✅.
